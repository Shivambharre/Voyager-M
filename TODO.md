# Implemented design actions

The actions below now use persisted app data and have active screens.

| Screen | Action | Result |
| --- | --- | --- |
| Home Archive | Resume | Opens the most recently updated incomplete lesson at its saved position. It does not start playback automatically. |
| Home Archive | Daily Goals | Shows today's playing time and manually completed lessons. Settings can change both daily targets. |
| Home Archive | Progress | Lists saved playback positions and completion status. Selecting an item opens that position. |
| Home Archive | Bookmarks | Lists saved moments. Selecting an item opens the saved position. Users can delete bookmarks. |
| Focused Study | Share Link | Opens the Android share sheet. Other platforms copy the link to the clipboard. |
| Focused Study | Save Moment | Saves or removes a bookmark at the current playback position. |
| Settings & Curation | App settings | Saves appearance, default playback speed, resume behavior, topic-completion confirmation, and daily-goal targets. |

Daily study time counts only while playback reports that it is playing. Lesson
completion is a manual action in the player. The default targets are 30 study
minutes and one lesson per day.
